Snowy Delivery — сборка игры
============================

Запуск: SnowyDelivery.exe

Управление
----------
W A S D   — движение машины
F         — фары
X         — печка (A / D — режим мощности)
Tab       — телефон (доставка, карта, банк, эвакуация, настройки)
E         — взаимодействие (заправка, забрать/сдать заказ)
Esc       — пауза / выход в главное меню

Сохранения
----------
3 файла, автосохранение каждые 5 минут и при выходе в меню.
Папка: %USERPROFILE%\AppData\LocalLow\DefaultCompany\SnowyDelivery\
Файлы: save_1.json, save_2.json, save_3.json

Для выгрузки достаточно отправить содержимое этой папки, кроме:
  SnowyDelivery_BackUpThisFolder_ButDontShipItWithYourGame
(это отладочные символы, для игры они не нужны)
